📌 Project Overview

This repository contains SEO Audit conducted for Foodsure.in. The goal of this project is to identify on-page SEO gaps, crawlability issues, and performance bottlenecks using automated data processing and visualization.

🛠️ Tech Stack & Tools

• Data Collection & Processing: Python (Google Colab)
• Data Storage: Google Sheets
• Data Visualization: Looker Studio (Google Data Studio)

🔍 Key Metrics Analyzed

• Crawl & Performance: HTTP Status Codes and Page Load Times (seconds)
• Metadata Optimization: Title & Meta Description lengths and missing tags
• Content & Structure: H1/H2 tag counts, Canonical URLs, and Word Counts
• Accessibility & Linking: Missing Image Alt texts and Internal Link distribution
